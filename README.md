# Azeroth Survivors — Windows downloads

Download the ready Windows build from [Releases](https://github.com/ahmedalqamzi/azeroth-survivors-downloads/releases).

1. Download **AzerothSurvivors-Setup-Windows.zip** from the release assets.
2. Extract that small ZIP, then double-click **Setup.bat**.
3. Setup downloads the three package parts, checks their SHA256 hashes, and extracts the game. Open **Play Azeroth Survivors.bat** in the resulting game folder.

The full download is approximately **5.47 GB**, including the WoW Data folder. Allow about **20 GB free disk space** during installation. Windows PowerShell and built-in .NET are sufficient; Python and a separate WoW install are not required.

The other release assets are the three large package parts and checksums. Setup downloads them automatically. GitHub's autogenerated **Source code** archives contain only this downloads repository, not the game.

## Multiplayer

Up to three players: one host and two guests. Use the same protocol-v5 release on every PC. Choose your own class, host a party from Multiplayer, and send both friends the same complete invite. Wait for all intended players before entering the world. Mid-run joins are refused. Each player chooses their own rewards with a 20-second fallback.

This is a prototype. Physical separate-network play and exhaustive duplicate-class three-player talent handling remain to be certified. The packaged build passed 4,641 unit tests with zero failures. No account saves are bundled or reset.

This repository distributes the prepared build; it does not mirror the game's source repository.
